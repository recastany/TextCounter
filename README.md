TextCounter — Part 2
Description

This project is a Java program that reads text entered by the user, one line at a time.

The program counts the total number of characters and the total number of lines entered by the user.

How It Works
The program reads text from the command line.
It counts the characters and lines.
The program stops when the user enters stop.
The word stop is not included in the character or line count.
The final results are displayed when the program stops.

Classes
MainTextCounter: Reads user input and displays the results.
TextCounter: Counts the lines and characters and checks whether the program should stop.
